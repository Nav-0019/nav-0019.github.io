Bridging the gap between raw incident logs and actionable business intelligence. This project demonstrates practical implementation of database design, SQL querying, and high-impact visualization.

Relational Integrity

The underlying `infra_system` MySQL database maintains strict relational integrity across Location, Issue Types, Departments, and Complaint fact tables.

It serves as a single source of truth for reporting area-wise complaints and tracking systemic resolution delays.

Data Analytics via DAX

Data models rely on advanced DAX functions to dynamically calculate delay metrics based on the difference between reported date and the current date.

The Power BI interactive dashboard exposes total complaint overviews, pending versus resolved states, and comparative performance of departments at a glance.
