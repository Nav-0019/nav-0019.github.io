Infrastructure Intelligence Dashboard

1 Introduction & Background

The Real-World Context: City administrations frequently struggle to manage and track the sheer volume of infrastructure complaints across different areas and departments.

The Existing Gap: Without proper visualization tools, it's nearly impossible to pinpoint operational bottlenecks, identify systemic resolution delays, or monitor departmental performance dynamically.

The Core Objective: Bridge the gap between raw, tabular incident logs and actionable business intelligence by designing a structured relational database integrated with an interactive Power BI dashboard.

2 Deep Dive into the Requirements

Key Challenges to Solve

  • • Data Modeling: Establishing strict relational integrity between Locations, Departments, Issue Types, and a central Complaints fact table.
  • • Delay Calculation: Dynamically computing resolution delays using precise DAX calculations.
  • • Trend Analysis: Visually tracking complaint trends (Pending vs Resolved) across diverse geographical areas.

Target Users

City Planners: Gaining high-level overviews of area-wise complaint distributions.

Department Heads: Reviewing comparative performance and addressing highlighted inefficiencies in resolution timelines.

3 Proposed Solution Architecture

High-Level Concept: An integrated pipeline where structured data flows from a robust MySQL database directly into an analytical Power BI reporting suite.

Data Layer

MySQL Relational DB

Query & Model

SQL Extracts + DAX

Visualization

Power BI Dashboard

Technology Stack Breakdown

Database Schema

MySQL `infra_system` utilizing normalized tables for Locations, Issue_Types, Departments, and a central Complaints fact table.

Business Intelligence

Power BI Desktop used for connecting directly to MySQL and rendering interactive filterable visual reports.

Data Operations

Complex SQL querying to structure raw data prior to ingest.

Calculations

Data Analysis Expressions (DAX) employed for dynamic KPIs like Days Delayed.

4 Key Insights & Observations

Dynamic Delay Metrics (DAX)

The core innovation of the dashboard is the real-time visibility into delays. Using calculated DAX formulas such as `DATEDIFF(complaints[reported_date], TODAY(), DAY)`, the system immediately flags inefficiencies.

Actionable Observations

Analysis revealed a balanced distribution of complaints across areas, but critically highlighted that a higher proportion of complaints remained in a pending state, pinpointing exact departmental bottlenecks.

5 Impact & Conclusion

Closing Summary: This project actively demonstrates the practical implementation of database design fused with modern BI visualization. By transforming raw complaint data into an interactive, visually compelling narrative, administrators can make data-driven decisions that actively improve infrastructure repair timelines.
