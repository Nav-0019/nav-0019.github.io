Dayflow brings clarity to HR workflows. Utilizing modern Web architectures, it perfectly aligns everyday work operations with a stunning, high-performance UI.

Architecture

Built with Next.js 14 App Router and TypeScript, Dayflow provides a seamless, server-rendered application experience.

Data flows securely through Prisma ORM to a PostgreSQL backend, strictly validated on all mutating endpoints using Zod schemas.

Security & UI

Authentication is driven by a robust JWT implementation featuring httpOnly refresh tokens and bcrypt password hashing. Role-Based Access Control (RBAC) middleware guarantees route safety.

The interface employs an aesthetic Glassmorphism and Canvas Wash design system via Tailwind CSS and Lucide React icons.
